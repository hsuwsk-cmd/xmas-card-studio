如何成為 AI Prompt 魔法達人？

Prompt 就是給 AI 的畫畫指令！越詳細，畫得越漂亮喔！

魔法 Prompt 4 要素黃金公式：

1. 主角
(Who)
2. 服裝動作
(Action)
3. 場景
(Where)
4. 畫風
(Style)

💡 範例比較：

❌
普通 Prompt (不夠具體)：
「聖誕小貓」
👉 AI 不知道小貓在做什麼、在哪裡，畫出來比較普通。
✅
達人級 Prompt (豐富具體)：
「可愛小貓戴著聖誕帽，在溫馨木屋的聖誕樹旁，3D動畫風格」
👉 包含了四大要素，AI 就能生成超級美麗精緻的畫作！
